# Verified Blender learnings

Keep reusable lessons supported by evidence: confirmed modeling failure causes, validated export settings, demonstrated deformation improvements, or useful print validation checks. Follow [the memory guide](../README.md).

Read matching lessons before similar work. Create a lesson only after verification:

```markdown
# Lesson

- Applies when:
- Last verified: YYYY-MM-DD
- Blender or tool version, when relevant:

## Observation
What happened and under which conditions.

## Evidence
Check results and links to files or previews.

## Future action
What the evidence supports doing next time.

## Limits
Conditions requiring revalidation.
```

A clean preview alone does not prove manifold geometry, walls, units, or exported dimensions. Record supporting checks. A failed connection identifies a blocker; it does not establish a root cause.

Keep untested ideas in [shorterm/](../shorterm/README.md). Update lessons when evidence changes and retire disproven advice. Do not create fictional production lessons during initialization. Promoting a lesson into a skill or permanent instruction requires authorization under [AGENTS.md](../../AGENTS.md).
